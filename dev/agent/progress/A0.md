- done:
  - `scripts/agent/make_golden.py`: runs a config (its own `release.seed`) via `python -m lpdm.main` under `/usr/bin/time -v`, from this checkout's `src/` (PYTHONPATH set, so a worktree is not silently run against the main checkout's editable install), and stores `footprint.npz` (dense float32 footprint + release times, compressed), `endpoint_particles.parquet`, `run_metadata.json` (output paths made portable) and `manifest.json` (git rev and src-dirty flag, config file and resolved-config SHA-256, device, seed, torch/CUDA versions, GPU name, met stores' provenance, GLIDE_COMPILE, wall time, peak RSS and GPU memory, file checksums). `--large` keeps data under `$GLIDE_AGENT_OUTPUTS` (or the main checkout's `outputs/`) and commits only the manifest; `--from-output` builds from a finished run (`--run-rev` records the rev it ran at).
  - `scripts/agent/compare_golden.py`: verifies fixture checksums, runs the fixture's config on its device (or takes `--output`), notes provenance differences, prints per release max |a-b|, max |a-b|/|b|, release total and its relative difference, cell/bound ratio, cells differing, and the largest of each criterion; PASS/FAIL exit status. Defaults: CPU bit-identical (footprint and endpoints); CUDA per cell |a-b| <= 1e-5|b| + 1e-7 max|b| (max over the release), release totals within 1e-6 relative, endpoints reported only. `--exact`, `--rtol`, `--atol-frac`, `--total-rtol`, `--endpoints` override.
  - `scripts/agent/benchmark.py`: runs with GLIDE_PHASE_TIMERS=1, parses the phase table and `time -v`, prints Markdown (footprints/s = releases / process wall), `--from-log` re-reports a finished run, `--json`.
  - `tests/test_golden_harness.py`: 8 tests (exact vs CUDA criteria, the absolute floor, relative cell limit, release-total limit, shape mismatch, phase-table and time-v parsing).
  - Fixtures: `tests/golden/smoke_mhd_single_release/cpu/` (0.37 MB, at 3cc2d70), `tests/golden/smoke_mhd_single_release/cuda/` (0.37 MB, at 3cc2d70), `tests/golden/ab_multisite_perf/cuda/manifest.json` with data in `outputs/golden/ab_multisite_perf/cuda/` of the main checkout (57 MB: footprint.npz 17 MB, endpoints 40 MB; run at 957ea3f, the claim commit; `src/` identical to 3cc2d70 and to main f09151c). The footprint compresses to 5.6 kB for the smoke run, so no further compression was needed.
