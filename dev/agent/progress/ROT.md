- reference issues:
  - FLEXPART v11 `turbulence_mod.f90` 644–662 (`windalign`), v10.4 `windalign.f90`: the direction is `1/max(|D|, 1e-30)` of the accumulated displacement D; if D is exactly zero, sinφ = cosφ = 0 and the boundary-layer turbulent displacement of that interval is dropped. Expected: some fallback axis. Effect: a corner case (exact zero), probably never hit with real winds; not quantified. GLIDE does not copy it.
  - FLEXPART's direction is that of the accumulated displacement over the synchronisation interval, which includes the mesoscale random displacement (`turbulence_mod.f90` 249–250, added before `windalign` at `advance_mod.f90` 273) and, for a particle that left the boundary layer mid-interval, the above-PBL turbulent displacement (`advance_mod.f90` 431–432). So FLEXPART's along-wind axis is perturbed by the meander noise. A design difference rather than an error; GLIDE uses the mean wind at the particle.
  - Not an issue, a difference: FLEXPART carries `turbvel%u`, `%v` wind-relative and never rotates them when the wind turns (decision 0032 compares; GLIDE's private `_carry_wind_relative` reproduces it).
