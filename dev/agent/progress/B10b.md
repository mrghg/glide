  - DATEM `stat_pgm/statmain/statmain.f` KSPARM (lines 1170–1199): a measured percentile counts towards KS only if some modelled percentile reaches it, so a model far too low (or zero everywhere) gets KS = 0, a perfect KS term. Synthetic case: predictions x1e-3 give KS 0 (term 1.00), x1e3 give KS 69 (term 0.31). Expected: a Kolmogorov–Smirnov distance, which penalises a distribution shifted either way (the DATEM description's wording was not rechecked in this session). Affects every published rank that used it: an under-predicting model gains up to 1 rank point on the KS term. GLIDE copies it (scores must follow the published protocol); the four terms are reported separately (validation-plan §3, Tier 3) so the effect is visible.
