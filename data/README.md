# Data

The datasets GLIDE validates against are **not redistributed with this
repository**. They are third-party model outputs and emissions inventories whose
licensing terms do not permit redistribution here. The folder structure is kept
so the configs, scripts, and notebooks resolve their expected paths once you
supply the files locally.

## What is expected here

| Path | Contents | Source |
| --- | --- | --- |
| `validation-timeseries/*.csv` | Per-site CH₄ enhancement timeseries derived from **NAME** (UK Met Office) and **FLEXPART** footprints. | Generated by `scripts/make_validation_timeseries.py` from NAME/FLEXPART footprints. |
| `FLEXPART/FLEXPART_*.nc` | FLEXPART footprint fixture used by the comparison notebook. | FLEXPART model output. |
| `EDGAR_CH4_2024_MHD_grid.nc` | EDGAR v2025 CH₄ 2024 total flux, regridded to the footprint grid. | EDGAR (CC-BY); https://edgar.jrc.ec.europa.eu/dataset_ghg2025 |
| `sample_met.zarr` | Small cropped ERA5 cube for the local smoke test. | Download with `scripts/download_sample_cube.py` (public ARCO ERA5). |
| `era5/<DOMAIN>_<YYYYMM>.zarr` | Monthly ERA5 pressure-level cubes read by the EUROPE configs (`data/era5/EUROPE_*.zarr`). Tens of GB each; symlink `era5/` to bulk storage. | `scripts/download_sample_cube.py --domain EUROPE --year-month YYYYMM` |
| `era5-model/<DOMAIN>_<YYYYMM>_ml.zarr` | The same on ERA5's 137 model levels. Kept apart from `era5/` so the configs' glob never mixes the two. | As above, plus `--levels model` |
| `$GLIDE_ETEX`, `$GLIDE_DATEM` (outside the repository) | Tracer-experiment observations: ETEX, CAPTEX and ANATEX. | JRC and NOAA ARL; see [tracer-experiments.md](tracer-experiments.md). |
| `$GLIDE_FLEXPART_SRC`, `$GLIDE_FLEXPART_OUTPUTS` and the other reference data for validation (outside the repository) | FLEXPART v11 source and its ERA5 reference runs, the ERA5 ensemble columns, and the other inputs the validation needs. | Listed in [docs/validation-plan.md](../docs/validation-plan.md) §8, with who provides each. |

## How to obtain the data

- **ERA5 met** — public; fetch a local subset with
  `scripts/download_sample_cube.py` (no credentials needed for the public ARCO
  buckets). This moves to [met-bazarr](https://github.com/mrghg/met-bazarr) in
  queue task B1.
- **EDGAR emissions** — public (CC-BY) from the EDGAR portal linked above;
  regrid to the footprint grid as in the validation script.
- **Tracer experiments (ETEX, CAPTEX, ANATEX)** — public, but both archives
  are awkward to download from. The full recipe, file formats and scoring are in
  [tracer-experiments.md](tracer-experiments.md).
- **NAME / FLEXPART validation timeseries and footprints** — **not public.**
  Please contact **Matt Rigby (matt.rigby@bristol.ac.uk)** for access.

Without the validation data the core model still runs end-to-end on the ERA5
smoke test (`configs/local_smoke_test.yaml`); only the validation/comparison
notebooks require the restricted datasets.
